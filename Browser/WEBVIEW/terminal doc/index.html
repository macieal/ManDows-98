ManDows 98 Terminal Documentation

Introduction

Welcome to the official documentation for the ManDows 98 Terminal. This terminal is part of the ManDows 98 system used in the game. Below you will find all supported commands and how to use them.

Available Commands

help
Displays the list of available commands.
Example:
C:\>help
about
Displays system information similar to neofetch.
Example:
C:\>about
clear / cls
Clears the terminal screen.
Example:
C:\>clear
echo
Prints text to the terminal.
Example:
C:\>echo hello world
date
Displays the current system date.
Example:
C:\>date
time
Displays the current system time.
Example:
C:\>time
whoami
Shows the current user.
Example:
C:\>whoami
ver
Displays system version.
Example:
C:\>ver
dir
Lists files in the current directory.
Example:
C:\>dir
tree
Displays a directory tree.
Example:
C:\>tree
uptime
Shows how long the system has been running.
Example:
C:\>uptime
calc
Performs math calculations.
Example:
C:\>calc 5+5
color
Changes the terminal text color.
Example:
C:\>color red
matrix
Displays a matrix-style binary animation.
Example:
C:\>matrix
hack
Runs a fake hacking animation.
Example:
C:\>hack
beep
Plays a short system beep sound.
Example:
C:\>beep
format c:
Simulates formatting the main drive.
Example:
C:\>format c:
random
Generates a random number.
Example:
C:\>random
reboot
Restarts the ManDows 98 system.
Example:
C:\>reboot
exit
Closes the terminal session.
Example:
C:\>exit
bin2text
Converts binary numbers into text characters.(developing)
Example:
C:\>bin2text 01001000 01101001
