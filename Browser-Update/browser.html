    About This Browser

    This is a custom web browser built using HTML, CSS, and JavaScript. It features a simple interface with navigation buttons and an embedded iframe for displaying web content.

    Created as part of the ManDows 98 project, this browser aims to provide a nostalgic browsing experience while showcasing modern web technologies.

    Feel free to explore and customize it to your liking!
